# PCB-timer-project

## Overview
This project is a digital electronic timer designed using a 4-digit 7-segment display and physical push buttons for user interaction. The timer allows the user to select a desired duration in seconds and provides visual feedback using LEDs.

## Functionality
- The timer uses a **4-digit 7-segment display** to show the selected time and countdown.
- **Plus (+)** and **Minus (−)** buttons allow the user to increase or decrease the number of seconds before starting the timer.
- Pressing the **Start** button begins the countdown.
- Pressing the **Start and Stop buttons simultaneously** stops the timer.
- When the timer reaches **zero**, the two LEDs blink to indicate completion.
- If the **Plus and Minus buttons are pressed simultaneously**, the timer is stopped and the two LEDs blink as a visual alert.

## User Interface
- 4-digit 7-segment display for time selection and countdown
- Start button
- Plus and Minus buttons for time adjustment
- Two LEDs for visual indication when the timer completes or is manually triggered

## Tools and Components
- 4-digit 7-segment display
- Push buttons
- LEDs
- Arduino Microcontroller
- resistors
- ceramic and electrolytic capacitors
- Designed and implemented using KiCad
- Debugged using a digital multimeter
